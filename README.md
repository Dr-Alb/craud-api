# craud-api
# 📦 Inventory Management System API

This project is a simple Inventory Management System built using **FastAPI** (Python) and **MySQL**. It allows users to perform **CRUD operations** on product inventory, including categories, suppliers, and stock entries.

---

## 🚀 Features

- Add new products, categories, and suppliers
- View, update, and delete existing products
- Track stock changes through stock entries
- Designed with clean RESTful architecture

---

## 🧱 Tech Stack

- **Backend:** FastAPI
- **Database:** MySQL
- **ORM:** SQLAlchemy
- **Data Validation:** Pydantic
